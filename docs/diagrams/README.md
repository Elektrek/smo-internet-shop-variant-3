# Диаграммы

Все исходники — PlantUML (`.puml`). Канонические схемы для защиты: `sequence/main-flow.puml`, `class/class-diagram.puml`, `flowchart/system-flow.puml`. Отдельные сиквенсы фиксируют Happy Flow и альтернативные ветви, чтобы их можно было рассматривать без увеличения большой диаграммы.

При изменении логики нужно синхронно обновлять основную диаграмму, краевые диаграммы, диаграмму классов и flowchart. Особенно важно сохранять триггеры: диспетчер постановки вызывается по ARRIVAL, диспетчер выбора — после постановки и завершения обслуживания.
